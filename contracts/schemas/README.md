# Esquemes canònics

Inclou `observation-state.schema.json` com a contracte versionat de l'estat
instrumental i `measurement-document.schema.json` com a contracte del document
de mesures angulars publicat pel backend.

Aquests esquemes validen missatges de bridge, deltes, components i descriptors de recursos. Són independents de Python i TypeScript i han de permetre generar tipus o verificadors en ambdós costats.
