# Domini científic i funcional

Cada subcarpeta correspon a una responsabilitat funcional. La separació interna és obligatòria:

- `models.py`: entitats, valors i invariants.
- `calculations.py`: càlculs científics purs i deterministes.
- `services.py`: composició de regles del domini.
- `README.md`: dependències, pendents i migració des de TerraLab.

El domini no importa aplicació, escena, infraestructura, Qt ni Three.js.
