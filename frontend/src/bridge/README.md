# Bridge científic

## Propòsit

Transportar comandes, esdeveniments i deltes entre TypeScript i Python, i coordinar handles binaris grans.

## Restriccions

- Sense `dict` o objectes arbitraris com a contracte estable.
- Sense Base64 per catàlegs, malles o textures.
- Amb generacions, versions, ACK, errors i recuperació explícits.
