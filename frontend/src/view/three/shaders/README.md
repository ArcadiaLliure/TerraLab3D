# Biblioteca de shaders

## Propòsit

Reservar responsabilitats per als shaders de cel, estrelles, Via Làctia, pols, terreny, atmosfera i postprocessat. Els shaders només reben paràmetres visuals i dades científiques ja resoltes.

## Prohibicions

- No calcular efemèrides ni accedir a catàlegs.
- No reconstruir recursos persistents per frame.
- No ocultar constants científiques sense documentar-les al domini.
