# Renderers de capes Three.js

Cada renderer és un adaptador visual especialitzat. Rep components i recursos neutrals, actualitza objectes Three.js retinguts i allibera només els recursos que posseeix.

Les capes previstes cobreixen cel, atmosfera, estrelles, traces, cossos, Via Làctia, pols, NGC, clima, horitzó, terreny, superfície, scope, mesures, constel·lacions i previsualització fotogràfica.
